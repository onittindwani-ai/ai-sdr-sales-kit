First release.

- 25 numbered answers to versions of "why not just use Salesforce, HubSpot, Clay or a tool", in 5 categories of 5: cost and setup, who runs it, results and trust, data, and switching. Each has what the client really means, a spoken answer, an email version, a follow up question, and when the tool is the better fit.
- A guide on who to sell to: the founder with no sales team, with an 8 sign score sheet and a walk away table.
- A one page offer template and a discovery call script.
- A comparison sheet of Salesforce Hunter, HubSpot Prospecting Agent and a done for you agency, using only documented facts checked on 2026-11-09.
- A paste in Claude Code quick start prompt, a Claude Code skill and 2 commands.
- `tools/personalize.py`, a standard library tool that fills every answer from your details, writes one playbook and audits it.
- 50 synthetic practice lines, 3 synthetic example configs with their built playbooks, and a synthetic sample call.
- `SOURCES.md`, `HONEST-LIMITS.md`, `tests/check_kit.py` and a GitHub Actions workflow.
