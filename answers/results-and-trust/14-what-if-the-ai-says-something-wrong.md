# 14. What if the AI says something wrong to a prospect?

**They say:** "What happens when the AI makes something up and sends it to one of my prospects?"

## What they really mean

They know AI can be confidently wrong, and they are the one who would have to apologise for it.

## Say it out loud

It can get things wrong, that's just true of AI, so the answer is not to let it run unchecked. Before anything starts, {{approval_step}}, the facts in the messages only come from what you've given us, and a person reads the replies, so software isn't answering anything tricky by itself. If a mistake does get through, you'll hear it from me first, and we'll fix the cause, not just that one message.

## Send it by email

Subject: If the AI gets something wrong

Hi,

It can happen, so we do not let it run unchecked.

Before anything starts, {{approval_step}}. The facts in each message come only from what you have given us. A person reads the replies, so the software does not handle anything tricky by itself.

If a mistake gets through, you will hear about it from me first, along with what we changed so it does not happen again.

{{your_name}}

## Ask this next

Which things must never be said in your name, so I can write them down as rules?

## When the tool is the better fit

If they have reps who can approve each message inside their own CRM, tools can give the same control. Salesforce's page says its agent can require rep approval. For a team set up that way, the software is a good answer.

Salesforce's outbound agent page (source 2), checked 2026-11-09. Only promise that a person reads replies if that is how you really run it.
